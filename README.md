# Vishal Soni — Portfolio

Blueprint-style portfolio built with Vite, React and TypeScript. Deployed at https://vishalsoni.netlify.app.

- `npm run dev` — local server
- `npm run build` — type-check and production build (output in `dist/`)
- `npm run lint` / `npm run format`
- `npm run build:v1` — rebuild the old portfolio (`legacy/v1`) into `public/v1`, served at `/v1`

Copy `.env.example` to `.env.local` and fill in the `VITE_ATM_*` values for the live ATM demo.
